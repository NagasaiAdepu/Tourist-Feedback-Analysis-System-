# NLP-Based Tourist Review Sentiment and Feedback Analysis System for Warangal

An NLP web application that analyses tourist reviews of Warangal's attractions (Thousand Pillar Temple, Warangal Fort, Ramappa Temple, Bhadrakali Temple, Laknavaram Lake, Pakhal Lake and others). It finds the **overall sentiment** of each review and the **sentiment for each aspect of the visit** (cleanliness, crowd, parking, ticket price, facilities, heritage, guides, scenery, safety). It then turns thousands of reviews into a **dashboard** and **action points** for tourism authorities.

## Features
| Area | What it does |
|---|---|
| **Sentiment analysis** | Hybrid model: TF-IDF + Logistic Regression (machine learning) combined with VADER (lexicon) extended with a tourism lexicon. Returns positive / neutral / negative with a confidence score |
| **Aspect-based sentiment** | Splits each review into clauses ("clean **but** crowded") and scores 9 aspects separately, with the sentence as evidence |
| **Keyword extraction** | Key phrases per review; typical topics of positive vs negative reviews (log-odds ratio) |
| **Dashboard** | KPIs, sentiment split, attraction ranking, monthly trend, aspect chart, keyword clouds, attraction × aspect heatmap, rating-vs-text mismatches; filters by attraction, visitor type and date |
| **Attraction insights** | Summary sentence, aspect breakdown, strengths to promote, issues with priority and recommended actions, best and worst reviews |
| **Feedback form** | Tourists submit a review with rating, date and visitor type and immediately see how it was understood |
| **Live analyser** | Paste any text to see preprocessing, probabilities, highlighted opinion words, aspects and keywords |
| **Bulk CSV upload** | Import survey or QR-form feedback with per-row validation, plus CSV export of analysed reviews |
| **Model performance** | Accuracy, precision, recall, F1 and confusion matrices for VADER, ML and Hybrid on two test sets |

## NLP pipeline
```
review text → cleaning (lower-case, URLs, contractions) → tokenisation → stop-word removal (negations kept)
            → light lemmatisation → TF-IDF (unigrams + bigrams) → Logistic Regression ─┐
review text → VADER + tourism lexicon ─────────────────────────────────────────────────┴→ Hybrid (60% ML + 40% VADER)
review text → sentences → clauses → aspect term matching → clause sentiment → aspect sentiment
```

## Results
| Model | Hand-written test set (60 reviews) | Held-out sample corpus (300 reviews) |
|---|---|---|
| VADER (lexicon) | 85.0% accuracy, F1 0.82 | 70.0% accuracy, F1 0.55 |
| TF-IDF + Logistic Regression | 65.0% accuracy, F1 0.61 | 94.3% accuracy, F1 0.93 |
| **Hybrid** | **91.7% accuracy, F1 0.91** | 91.3% accuracy, F1 0.90 |

The hybrid combines the strengths of both: the ML model learns domain patterns, and VADER generalises to new wording. The live numbers are on the **Model performance** page.

## Dataset (please read)
Public review sites do not permit scraping and redistributing their reviews, so `datasets/warangal_reviews.csv` is a **synthetic sample corpus of 1,500 reviews**, generated by `scripts/generate_dataset.py` from phrase banks. Each attraction has a realistic quality profile, so for example Ramappa Temple scores high on heritage and low on road access. Labels come from the star rating (4–5 positive, 3 neutral, 1–2 negative).
`datasets/eval_reviews.csv` holds **60 hand-written reviews** written independently of the generator. It is the fairer test of real-world accuracy. The tourism lexicon was built from the corpus vocabulary only, never from this test set.
To use real feedback, collect reviews (for example through the feedback form, QR codes at sites or surveys) and import them on the **Bulk upload** page.

## Setup & run
```bash
python -m venv .venv
.\.venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```
Open **http://127.0.0.1:8000** · API docs: http://127.0.0.1:8000/docs

On first start the model is trained (a few seconds) and the 1,500 sample reviews are loaded. To start with an empty system, set `NLP_SEED_SAMPLE=0`. In VS Code, press **F5** ("Run Warangal Review Insights").

## Tests
```bash
python -m pytest -q
```
15 tests cover preprocessing, VADER mapping, hybrid sentiment, aspect extraction with contrast words, keywords, recommendation rules, all API endpoints, validation, CSV import, dashboard numbers, insights, export, model evaluation and data seeding.

## Project structure

```
  attractions.py              # the 9 Warangal attractions

    aspects.py                # aspect lexicon and aspect-level sentiment
    keywords.py               # review keywords, positive vs negative topics

  services/
    analytics_service.py      # dashboard, attraction insights, CSV export
    evaluation_service.py     # accuracy / precision / recall / F1 / confusion matrix
frontend/  index.html · styles.css · app.js
datasets/  warangal_reviews.csv (sample corpus) · eval_reviews.csv (hand-written test set)
scripts/generate_dataset.py
tests/test_app.py
```

## Limitations
- The training corpus is synthetic; accuracy on real reviews must be confirmed with real labelled data.
- English only. Telugu, Hindi and code-mixed ("Tenglish") reviews are not yet supported.
- Aspects are found with a keyword lexicon, so unusual wording can be missed. Sarcasm is not detected.
- No login: the dashboard and delete actions are open. Add authentication before public deployment.

## Future work
Real data collection with QR codes at each site, Telugu and code-mixed language support, transformer models (for example IndicBERT or multilingual BERT), sarcasm handling, authentication with official and tourist roles, email alerts for spikes in negative feedback, and deployment for the Telangana tourism department.
